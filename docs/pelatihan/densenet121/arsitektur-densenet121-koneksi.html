Arsitektur DenseNet-121 — Dense Connectivity (exp_005)

Ciri khas DenseNet: setiap lapisan terhubung ke semua lapisan berikutnya lewat concatenation

Dense connectivity

  • • Masukan lapisan ke-l = concat [x₀,x₁,…,x₍l-1₎]
  • • Blok 121: 6, 12, 24, 16 dense layer
  • • Tiap dense layer menambah k=32 peta fitur
  • • Fitur dipakai-ulang → gradien & efisiensi parameter

Isi satu dense layer (H_l)

  • • BN → ReLU → Conv 1×1 (bottleneck 4k)
  • • BN → ReLU → Conv 3×3 (hasil k=32)
  • • Keluaran di-concat, bukan dijumlah (beda dari ResNet)

Transition & transfer learning

  • • Transition: Conv 1×1 + AvgPool 2×2 (kanal ½, spasial ½)
  • • Seluruh backbone BEKU (bobot ImageNet)
  • • Hanya classifier 1024→7 dilatih (7.175 param)
